KOLER — Visual Design Editor

How to use

Bu sayfada siteyi görsel olarak düzenleyebilirsin.

1. Aşağıdaki sitedeki bir başlığa çift tıkla ve metni değiştir.
2. Bir elementi seçip sürükleyerek konumunu değiştirebilirsin.
3. Değişikliklerini yaptıktan sonra Save Design butonuna bas.
4. Kaydedilen tasarım bu tarayıcıda korunur.

Not: Bu ilk sürüm görsel düzenleme içindir. GitHub dosyalarına otomatik commit atmaz; önce tasarımı birlikte oturtuyoruz.

Hazır.
